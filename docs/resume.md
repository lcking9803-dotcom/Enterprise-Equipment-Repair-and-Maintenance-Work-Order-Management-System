**企业设备报修与运维工单管理系统（含故障分析模块）**

技术栈：Spring Boot 3、MyBatis-Plus、MySQL、Redis、JWT、Vue 3、ECharts、MinIO、Python/Pandas、Docker

- 设计并实现设备台账、故障报修、工单受理派发、维修处理和验收关闭流程，基于角色与数据范围限制不同岗位的查询和操作权限。
- 使用状态机、事务与乐观锁保证工单流转和审计日志一致，处理重复受理、并发派单、越权维修和验收驳回等异常场景；当前已完成 7 项后端自动化测试及 1 项 Python 指标测试。
- 基于 `[实际数据量]` 条脱敏模拟工单实现 FRT、MTTR、SLA、故障帕累托和人员工作量分析；通过索引优化将 `[具体查询]` 的 `[平均/P95]` 耗时从 `[实测值]` 降至 `[实测值]`，并使用 Docker Compose 完成部署。
