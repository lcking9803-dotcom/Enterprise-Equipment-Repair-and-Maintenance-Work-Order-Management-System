# 3—5分钟演示脚本

1. **0:00—0:25 项目定位**：说明系统解决设备故障从报修到验收缺少闭环和责任追踪的问题。
2. **0:25—0:55 设备台账**：展示设备编号、位置、责任部门、状态和保养日期。
3. **0:55—1:25 报修**：使用报修账号创建紧急工单，说明优先级如何决定SLA。
4. **1:25—2:00 受理派单**：切换调度账号受理并派给维修人员，展示角色按钮差异。
5. **2:00—2:35 维修与附件**：维修账号提交维修说明、费用和照片。
6. **2:35—3:10 验收驳回**：验收账号先驳回，展示工单回到维修中和审计记录。
7. **3:10—3:35 再次维修并通过**：通过验收后工单关闭、设备恢复运行。
8. **3:35—4:10 看板与导出**：展示 FRT、MTTR、SLA、故障排行和Excel导出。
9. **4:10—4:40 技术证据**：展示状态机测试、乐观锁409、ER图和 Docker 服务状态。

录屏只能展示实际运行结果；不要配上未经验证的并发量或性能数字。
